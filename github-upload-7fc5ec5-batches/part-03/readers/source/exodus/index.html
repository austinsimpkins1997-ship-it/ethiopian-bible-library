Geʽez Exodus source pages

Local copies of Ran HaCohen's 40 chapter pages from Dillmann's historical Octateuch edition. The text is a digitizer's transcription, not an independently collated edition. This Geʽez source-page set contains no English text; the separately identified Brenton English companion is built from its own captured pages.

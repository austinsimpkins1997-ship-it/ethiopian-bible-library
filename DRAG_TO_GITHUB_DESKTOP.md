# Drag this package into your GitHub clone

1. Open the cloned repository in Explorer from GitHub Desktop (**Repository → Show in Explorer**).
2. Drag the clone's root folder onto `COPY_TO_GITHUB_REPO.bat` in this package.
3. Check the printed paths and type `COPY` to proceed.
4. Wait for the checksum verification, then review changes in GitHub Desktop.

This preserves `.git` and never deletes files that exist only in the clone. It does not commit, push, or publish. For full details, read [START_HERE.md](START_HERE.md).

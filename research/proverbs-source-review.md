# Proverbs source review

Inspected [Beta maṣāḥǝft LIT3927Messale](https://betamasaheft.awhamburg.de/works/LIT3927Messale/text) and the source file pinned at [Works commit 2574a6c84ed477af76122a6b112df3bbf45a96f5](https://github.com/BetaMasaheft/Works/blob/2574a6c84ed477af76122a6b112df3bbf45a96f5/3001-4000/LIT3927Messale.xml). The source file is 212,903 bytes (SHA-256 `474193ee1bbc75fdc8f83bfe25e409134035ab4672395494b823728ae8c9f225`); the full file is not retained in the public site. Its sole Geʽez edition is labeled ‘Text of the EOTC printed Bible.’ The Beta maṣāḥǝft page says the text was digitized from modern Vulgata printed editions and converted to XML by its team.

The file-level notice says CC BY-SA 4.0. The University of Hamburg [data note on the dataset](https://www.fdm.uni-hamburg.de/en/uhh-data-notes/data-notes/issue-2020/dano-01-001.html) says each file has its own license statement, defaulting to CC BY-SA 4.0 where no file-level statement is present. Beta maṣāḥǝft’s current site Guidelines separately state CC BY-NC-SA 4.0. The data note does not resolve that discrepancy or establish rights in the unidentified printed exemplar. The project’s [content policy](../CONTENT-LICENSES.md) says not to bundle text while reuse terms conflict or remain unclear, so no scripture wording or source XML is included.

The pinned file has 26 ordered chapter divisions and 766 labeled line elements, each linked to a reference target. These are source-structure counts only. The [Encyclopaedia Aethiopica article on biblical wisdom books](https://en.sewasew.com/p/wisdom-books-biblical) describes the traditional split as Méssale (Proverbs 1–24) and Tägíasä Sälomon (Proverbs 25–29), and cites other canon enumerations. The TEI’s 26 divisions are not shown to correspond to either scope. This remains an uncertain edition lead, excluded from canon-linked reader coverage. No wording is bundled.

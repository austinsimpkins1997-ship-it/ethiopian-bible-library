# Beta maṣāḥǝft scripture-file license audit

## Evidence

The [current Beta maṣāḥǝft Guidelines](https://betamasaheft.awhamburg.de/Guidelines/?id=catalogueworkflow) describe data on project pages and in files, and remixes of that data, under **CC BY-NC-SA 4.0**. The [University of Hamburg version 5.2 dataset record](https://www.fdr.uni-hamburg.de/record/9784) reports dataset-level **CC BY 4.0** metadata and says each file carries specific attribution. The UHH [TEI-XML data note](https://www.fdm.uni-hamburg.de/en/uhh-data-notes/data-notes/issue-2020/dano-01-001.html) describes the dataset as CC BY-SA 4.0 and says each file carries a specific license, defaulting to CC BY-SA 4.0 when none is stated.

The archived Works TEI files each state **CC BY-SA 4.0**. The current Guidelines and versioned repository metadata do not explain its precedence or the underlying printed-source rights. The archive therefore marks the affected records **mixed**, withholds their text from the public bundle, and links both provider records. It does not claim that the conflict is resolved or that the file license clears rights in the printed exemplar. Do not infer commercial or unrestricted reuse from this archive.
